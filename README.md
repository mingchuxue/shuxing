# 数形 · 函数画板

面向高中数学的交互作图工具，可在浏览器中直接使用，也支持安装到手机离线打开。

- **函数作图**：同时绘制多条 \(y=f(x)\) 曲线。输入支持 \(\sin\cos\tan\ln\log\sqrt{\,}\lvert\,\rvert\) 与幂运算，可写 `2x`、`π`、`e`，也可用 `a*sin(b*x+c)` 这类带字母系数的式子，字母会自动变成滑块。分段函数可用课本写法 `{x^2, x<0; 2x, x>=0}`，也可用 `x<0?x^2:2x`。
- **读图**：拖拽与滚轮（触屏可双指）缩放平移；可选 π 刻度；指针追踪坐标。自动标出零点、极值与交点。
- **导数**：显示 \(f'(x)\) 图像，并可拖动切线，同时读出该点的斜率。在尖点等不可导处会标明「不可导」，并给出左右导数，而不会画出一条乱跳的切线。
- **不等式区域**：输入 `y>x^2` 或 `x^2+y^2<1` 这类不等式，会给满足条件的区域着色并画出边界。
- **定积分**：打开「积分」后拖动区间端点，可读出定积分的值与对应面积。
- **性质与取值**：自动分析奇偶性、周期、定义域提示和当前窗口内的单调区间，并列出对应的函数值表。
- **圆锥曲线**：用方程绘制圆、椭圆、双曲线、抛物线，例如 \(x^2/4+y^2/9=1\)。对标准形式标出焦点、准线、渐近线等。
- **参数与极坐标**：如 `x=cos(t), y=sin(t)` 或 `r=2*cos(θ)`。
- **图库**：收录高中常见函数与图像变换，每条附一句说明。
- 导出 PNG、通过链接分享当前图像、自动记住上次的式子与窗口。支持深色模式。

表达式与进度保存在本机浏览器中，不会上传到网络。
